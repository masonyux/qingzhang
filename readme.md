# 轻账 · 信用账单与负债管家（iPhone 可安装 App）

这个项目把原来的 `code_artifact.html` 改造成了一个**可安装到 iPhone 主屏的 PWA（渐进式 Web 应用）**：

- ✅ 打开后**全屏运行**，像原生 App 一样，有自己的图标和名称「轻账」
- ✅ **完全离线可用**（Tailwind、FontAwesome 图标、字体全部本地化，不再依赖网络/CDN）
- ✅ 数据 **100% 保存在你手机本地**（localStorage），不上传任何服务器

## 二、安装到 iPhone（三步，约 3 分钟）

### 第 1 步：把它发布到网上（免费，任选一种）

> PWA 需要 HTTPS 才能安装。随便选一种免费托管即可。

**方法 A — Netlify Drop（最简单，无需写代码）**
1. 电脑浏览器打开 <https://app.netlify.com/drop>
2. 把整个项目**文件夹**拖进去（把 zip 解压后拖里面的文件夹）
3. 等几秒，得到网址，例如 `https://xxxxx.netlify.app`

**方法 B — GitHub Pages**
1. 新建一个 GitHub 仓库，把文件夹里的内容上传
2. 仓库 → Settings → Pages → Source 选 `main` 分支根目录 → Save
3. 得到网址 `https://你的用户名.github.io/仓库名/`

> 也可以用 Vercel、Cloudflare Pages，效果一样。

### 第 2 步：用 iPhone 添加到主屏

1. 用 iPhone 自带的 **Safari** 打开上面得到的网址
   （⚠️ 必须用 Safari，不能用微信内置浏览器）
2. 点 Safari 底部中间的「**分享**」按钮（方框 + 向上箭头）
3. 向下滑动，点「**添加到主屏幕**」（Add to Home Screen）
4. 名称保持「轻账」，点右上角「**添加**」
5. 回到主屏即可看到「轻账」图标，点开即**全屏运行**，和原生 App 体验一致

### 第 3 步：验证离线可用

1. **先联网**用 Safari 打开一次，等页面**完全加载完**（图标、卡片都显示出来，通常 1–2 秒即可），这一步才会把全部资源缓存下来
2. 打开**飞行模式 / 关闭 Wi-Fi 和蜂窝网络**
3. 再点主屏的「轻账」图标（或在 Safari 里刷新同一页面）——能正常打开就说明离线成功

> ⚠️ 如果断网后打不开：多半是第一次没有“联网加载完整”就断网了。请**联网重新打开一次、等页面加载完**，再试离线。

## 三、数据安全（重要）

- 所有账单、贷款、流水都保存在**你自己手机的浏览器本地**，不上传任何服务器
- 建议定期用 App 内「**流水/备份**」页的「**导出 JSON 备份**」功能，把备份文件存到微信收藏或文件管理里
- ⚠️ 清除 Safari 网站数据会清空本地数据，请务必定期备份

## 四、常见问题

**Q：为什么一定要用 Safari？微信里打开不行吗？**
A：只有 Safari 支持「添加到主屏幕」安装为 App；微信内置浏览器没有这个功能，且两者数据不互通。

**Q：图标没显示 / 点开是白屏？**
A：先正常联网用 Safari 打开一次，等页面加载完图标和全部资源，再添加到主屏。

**Q：iPhone 上没有弹出「安装」提示？**
A：iOS 不像安卓那样弹「安装」提示，必须手动「分享 → 添加到主屏幕」。

**Q：想清空数据重新开始？**
A：App 内「流水/备份」页有「清空所有数据」按钮。

**Q：离线打开是白屏 / “Safari 无法打开页面”？**
A：说明离线缓存没生效。请按顺序处理：
1. 联网用 Safari 打开一次，**等页面完全加载完**再关掉（别急着断网）
2. 如果之前装过旧版本，**长按主屏「轻账」图标 → 删除 App → 重新「分享 → 添加到主屏幕」**，然后联网打开一次再测离线
3. 确认网址是 `https://` 开头（不是 `http://`）——只有 HTTPS 才能启用离线缓存

**Q：打开正常，但之前录的数据没了？**
A：这是「本地数据」被清掉了，跟离线缓存不是一回事。数据只存在手机浏览器本地，清除 Safari 网站数据、或长时间不用被系统回收都会丢。**务必定期用「导出 JSON 备份」存一份到微信收藏**，丢了随时「导入恢复」。

## 五、信用贷还款方式与「一次录入、自动更新」

信用贷/分期卡片现在支持三种还款方式，并能按利率自动生成完整还款计划：

- **等额本息**：每月固定；填「本金 + 年利率」自动算月供。
- **等额本金**：首月最高、逐月递减；自动计算每期「应还 / 本金 / 利息 / 剩余本金」。
- **先息后本**：每月只还利息、到期一次性还本金。

**推荐录入方式（一次输入好，之后自动更新）：**

1. 填「贷款总金额 / 本金」+「年利率」+「总期数」+「每月扣款日」。
2. 填「首次扣款年月」，并勾选「**按月自动推进期数**」。
3. 之后应用会按当前日期**自动滚动已还期数、剩余本金、剩余待还**，无需每月手动改期数。
4. 每月到期点卡片上的「**核销本期**」记一笔即可；点「**还款计划**」可查看每一期的月供/本金/利息/剩余本金明细。

> 只记得月供、不记得利率也没关系：填了月供，应用会自动反推年利率并生成计划。
